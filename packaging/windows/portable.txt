TSPdf portable mode

While this file sits next to tspdf.exe, TSPdf keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the TSPdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move TSPdf with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\TSPdf and
%LOCALAPPDATA%\TSPdf) instead. If TSPdfData can't be written (for example on a read-only
drive), TSPdf says so and uses the per-user folders instead.
